# Review package: placebo-adjusted distance as the main outcome

This directory is an isolated analysis workspace for comparing three outcome
definitions without changing the manuscript or its current tables and figures:

1. the observed distance, `I`;
2. the placebo-adjusted distance, `I - M`;
3. the observed distance controlling flexibly for `M`.

All generated files are written under `outputs/`. The scripts read the existing
replication data and benchmark files but do not overwrite them.

## Benchmark calculation after integration (2026-10-06)

The production entry point is now `../1_1_calculate_indices.R`, section 7. It
calls the single shared `../programs/build_placebo_donor_matrices.R` for CCEI,
HM, MaxMPI and risk aversion, using the balanced pair roster, actual indices
and choice data from `1_1_calculate_indices.R`. New full outputs go to `../results/benchmarks/` and
the benchmark columns are carried through `2_1_build_panel.R`, `2_2_build_panel_group.R`,
and `2_3_build_panel_individual.R`. Section 7 can resume
from the actual-index checkpoint without recalculating the preceding indices.

The pre-integration scripts and panel files are preserved locally in
`../Archive/M_before_integration_2026-10-06/`. Existing benchmark outputs and
manuscript results remain in their original locations for comparison. The
review analyses below still consume those retained inputs; switching their
tables and figures to the new full benchmarks is a subsequent step.

The redundant review launchers 01 and 04 and historical pilot launcher 04a
were removed on 2026-10-06; copies are retained locally in
`../Archive/draft_figures_A7_4_2026-10-06/Code/IminusM_review/`.
Main `1_1_calculate_indices.R` is the entry point for all full benchmark calculations.
`02_ccei_ra_analysis.do` still reads the retained
`outputs/data/ra_placebo_member_wave.dta`. The old caches have no input/config
identity and cannot be resumed by the new builder. No full calculation was
run during integration or the manuscript figure update.

## Table A5 full-benchmark migration (2026-10-06)

Table A5 is now fitted directly by the standalone alternative-measure section
of `../08_Tables_Appendix.do`, using actual distance with M as a control and
the six Table 3 specifications. Full HM and MaxMPI benchmarks are generated
by section 7 of `../1_1_calculate_indices.R` into `../results/benchmarks/`;
`PLACEBO_MEASURES=hm,maxmpi` selects just those builds and `PLACEBO_CORES`
sets parallel workers. Both builds include all 651 non-own same-wave
donors, without a time cap. Existing RA benchmarks already include all 651
donors and remain the Panel C input.

The shared builder uses `../programs/rp_donor_costs.cpp` via Rcpp for full
HM/MaxMPI donor costs. Difficult MaxMPI searches finish with an uncapped
`highs` mixed-integer model that enforces one simple cross cycle and proves
its optimum; no unfinished cost is replaced by a neutral value. Objective
scaling and tightened feasibility/duality tolerances keep the optimality
check at 1e-10 in money-pump units. MaxMPI distributes donors across workers
so difficult targets can use all requested cores. Install
Rcpp and highs with `install.packages(c("Rcpp", "highs"))`. Cache identity
includes the native source hash and HiGHS version. The R algorithms remain
the reference for actual indices and historical capped pilots. The hybrid
results matched all 199,512 saved HM costs and 81,640 completed MaxMPI costs,
every own-pair index, exhaustive enumeration on 102 small graphs, and 300
independently solved costs from completed full-benchmark chunks. Validation
logs are in `../Logs/01_*validation.log` and `../Logs/01_mpi_bruteforce.log`.
The archived native-only configurations document the verified cache migration;
future reuse still requires matching inputs, code and calculation settings.

Review 05 and its retained outputs document the old 50/20-donor comparisons;
they no longer generate the manuscript's Table A5. The review exporter copies
08's canonical `../results/tables/table_bargaining_alternatives_M.tex` rather
than rebuilding it from pilot estimates. The full Table A5 log is
`../Logs/08_alternative_full.log`, and its coefficient export is
`../results/tables/table_bargaining_alternatives_M.csv`.

Full run completed: each measure contains 850,208 target-donor rows, including
1,304 own-pair checks, and 2,608 member-wave M summaries with 651 non-own
donors each. Full-matrix validation checks unique keys, nonnegative/monotonic
costs, index bounds, and adding-up identities. The wide panel preserves all
652 pairs and every pre-existing value outside the HM/MaxMPI benchmark fields.
Logs are `../Logs/01_full_A5_benchmarks.log`,
`../Logs/01_full_benchmark_validation.log`, and
`../Logs/01_wide_benchmark_validation.log`.

All 18 Table A5 regressions passed their sample/64-cluster checks. The six RA
fits reproduce the retained full-benchmark estimates to within 1e-7 (the
old export rounded some fields). Column (3) coefficients are -0.070605 for HM
and -0.077653 for RevMaxMPI. Column (6) standardized effects are -0.120929 and
-0.168570. The HM gap p-value is 0.011008, so the common significance level
in the existing main-text sentence is now 5%, replacing 1%. All other wording
is unchanged; the obsolete pilot note remains for a separately authorized
wording revision. `../Logs/08_A5_result_validation.log` records the checks.

## Table A5 sample alignment (2026-10-10)

All three panels now use Table 3's exact 2,560 student-wave observations
with defined CCEI-based distance. All alternative outcomes are defined on
this sample. Individual fixed effects retain the same 48 single-wave
students with `keepsingletons`; each of the 18 fits asserts that its
`e(sample)` equals the Table 3 availability indicator and has 64 class
clusters. The donor benchmarks and control specifications are unchanged.

The canonical table and coefficient CSV were regenerated by the standalone
A5 section of `08_Tables_Appendix.do`. Column (3) coefficients are
-0.070605 (HM) and -0.077653 (RevMaxMPI), or 29.0% and 26.5% of outcome
SDs on the common sample. Column (6) standardized effects are -0.120018
and -0.166517; both remain significant at 5%. The draft table, sample
note, and main-text effect sizes reflect this run. Sample sizes
and validation results under earlier dated headings are historical.
