# Legacy placebo-normalized analysis scripts (2026-10-10)

These four scripts were moved unchanged from active `Code/` at the user's request:

- `Code/99_7_placebo_normalized_regressions.do`
- `Code/99_8_placebo_normalized_figures.R`
- `Code/programs/placebo_normalized_regressions_one_measure.do`
- `Code/99_22_table4_placebo_normalization.do`

They produced the older placebo-normalized regression tables, binscatters,
diagnostics, and former Table 4. No active scripts call these entry points, and
their outputs are unused by the current `Overleaf/main_v3.tex` manuscript.
Current regression tables are generated by `Code/06_Tables_Main.do` and
`Code/08_Tables_Appendix.do`; current figures by `Code/07_Figures_Main.R` and
`Code/09_Figures_Appendix.R`.

The original folder structure is preserved here for reference. Benchmark data
and donor matrices remain in `Code/results/placebo_normalized/`, because current
analyses still use them. Other generated outputs remain in their existing locations.
