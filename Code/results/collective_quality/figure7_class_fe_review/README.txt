Figure 7 review: class fixed effects only
Historical review snapshot. Its analysis is now generated by the Figure 7 section of Code/4_Figures_Main.R and programs/class_fe_category_summary.R.
Model: outcome ~ low_low + high_high | class; Low-High is the reference category.
Uses the original 1,304 pair-waves, pooled-median classification, and 64 classes.
Class-clustered CR1 standard errors match existing Table A7 column (1).
Adjusted mean k = overall outcome mean + (category k dummies - sample dummy means)' category slopes.
Bars standardize all categories to the same sample-weighted distribution of classes.
Bar CIs: percentile whole-class bootstrap with category slopes and normalization re-estimated in every draw; 9,999 draws, seed 20261011.
Bracket tests use the original class-clustered CR1 covariance and t(63).
CDFs are empirical distributions of outcome - fitted class effect + its pair-wave-weighted mean.
This additive adjustment preserves within-class variation but permits values outside [0,1] and shifts endpoint masses.
CDFs are descriptive; no distributional hypothesis tests are reported for the generated adjusted outcomes.
