Section 6 collective-quality pipeline

Run from Code. Main estimates/plots are in 3/4; appendix estimates/plots are
in 5/6. The former standalone 11/12 scripts have been removed.

1. Main estimates: 3_Tables_Main.do, section headed "Figure 8 estimates".

   programs/build_collective_analysis_sample.do imports
   ../TalkFile_ceiv_fresh_3dp.csv, preserves its endpoint-attainment flags, and
   builds data/panel_group_new_indices.dta and data/collective_analysis_sample.dta.
   The group CEIV panel also supplies Table 1. The helper is called before
   Table 1 and in the independently runnable Figure 8 and appendix sections.
   Output: joint_outcome_linear_ame.csv.
   Log: Logs/3_collective_outcomes.log.
   Figure 8 uses Class FE, Class FE + controls and Pair FE + controls, with
   class-clustered t(63) intervals on 1,304 pair-waves and 64 classes.

2. Main plots: 4_Figures_Main.R, sections for Figures 6--8.

   Figure 6 checks outcome shares against the main LPM export. Figure 7 reads
   the common sample and writes four group_{ccei,ceiv}_{bar,cdf}.pdf panels.
   Figure 8 writes figure8_lpm_ame_{maximum,minimum}.png.
   The main script has no appendix-estimation dependency and generates no
   legacy unadjusted plots, choice-exclusion appendix plot or chat composites.
   All manuscript assets go to results/figures/collective_rationality and
   their existing Overleaf paths. Counts, means and contrasts are exported here.
   To run Figure 7 alone, load haven/ggplot2/dplyr, define paper_theme and
   sig_mark as above, and set code_dir to Code. Its class-FE helper is sourced
   by the section. Figure 8 defines its own paths and sources the AME plot helper.

3. Appendix estimates: 5_Tables_Appendix.do.

   "Collective-outcomes appendix table" prepares the sample, estimates the six
   categorical regressions, exports table5_coefficients.csv/table5_diagnostics.csv
   and writes collective_ccei_ceiv_categories.tex. Low--High is omitted.
   Log: Logs/5_collective_categories.log.

   "Figures A10 and A12 estimates" prepares its own sample and exports
   joint_outcome_ame.csv plus extensions/joint_outcome_shapley_{r2,models,coalitions}.csv.
   A10 uses class FE and class FE + controls in multinomial logit, with
   class-clustered normal intervals. A12 decomposes overall R2 for the four
   controlled Class-FE and four controlled Pair-FE LPMs. Its five blocks include
   individual CCEIs, student characteristics, friendship, corner/midpoint shares
   and fixed effects. All 32 coalitions use the same sample; contributions sum
   to the full model's R2 and percentage shares sum to 100.
   Log: Logs/5_collective_outcomes.log.

   "Figure A11 estimates" prepares its own sample and exports
   extensions/alternative_linear_ame.csv for HM and RevMaxMPI LPMs.
   Log: Logs/5_collective_alternatives.log.

4. Appendix plots: 6_Figures_Appendix.R, independently runnable A10--A12 sections.

   A10 reads joint_outcome_ame.csv from 5 and writes figure6_a_ame_*.png.
   A11 reads alternative_linear_ame.csv from 5, exports alternative_sd_units.csv
   and writes alternative_{HM,MaxMPI}_lpm_ame_{maximum,minimum}.png.
   A12 reads decomposition/full-model exports from 5 and the main LPM exports
   from 3, and writes joint_outcome_shapley.pdf plus a PNG preview.
   All panels retain their existing output paths and styling. Figure 8/A10/A11
   effects are percentage points per one-SD increase; stored effects are per
   0.1 units. CCEI SDs are 0.058234780484 (higher) and 0.151319396465 (lower).

Current sample: 1,304 pair-waves, 652 pairs, 64 classroom clusters.
CEIV endpoint status uses ceiv_at1 from the supplied attainment flag, since two
nonattained observations round to 1.000. Individual CCEI categories use the
pooled median across both waves (0.9806594): 348 Low-Low, 608 Low-High, 348 High-High.
Figures 3 and 7 include class FE without additional controls. Predicted means
use the same sample-weighted class composition for every category, and equal
the category averages of the class-adjusted outcomes used in the CDFs. Both
figures use normal mean +/- 1.96 SD/sqrt(n) intervals. Contrasts use
class-clustered CR1 and t(63). CDFs remove estimated class effects and restore
their weighted average. KS p-values use ordinary asymptotic two-sample tests,
treating adjusted values as observed. No bootstrapping is used in either figure.
Adjusted Figure 7 values may exceed one. Draft figure notes await revision.
