\noindent
This note compares the original revealed-preference distance index,
$\oldindex$, with the new cross-partition index, $\newindex$.
For both indices, lower values indicate that an individual's choices are
closer to the corresponding group choices and therefore indicate greater
revealed influence on the group decision.
